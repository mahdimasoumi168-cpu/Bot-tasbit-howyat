## پایگاه داده
D1 جداگانه ساخته شده و شناسه آن در `cloudflare/wrangler.toml` آمده است. این پایگاه داده مستقل از Railway است. برای ایجاد یک پایگاه تازه:

1. `cloudflare/schema.sql` را اجرا کنید.
2. فقط یک بار migration `cloudflare/migrations/0002_compatibility.sql` را اجرا کنید.

نمونه:
```sh
npx wrangler d1 execute bot-tasbit-howyat-migration --remote --file=cloudflare/schema.sql
npx wrangler d1 execute bot-tasbit-howyat-migration --remote --file=cloudflare/migrations/0002_compatibility.sql
```

## Secretها
در داشبورد Cloudflare، Worker با نام `bot-tasbit-howyat-migration` را باز کنید و در Settings → Variables and Secrets، `BOT_TOKEN` را به‌صورت Secret اضافه کنید. مقدار توکن را در GitHub یا پیام‌های چت قرار ندهید. اگر Secret webhook استفاده می‌شود، `WEBHOOK_SECRET` نیز باید به‌صورت Secret تنظیم شود. هنوز webhook را تنظیم نکنید.

## قیمت‌ها و فعال‌سازی خدمات
تعرفه‌ها در D1 مهاجرتی عمداً روی صفر و خدمات غیرفعال قرار گرفته‌اند، چون قیمت‌های تاریخی در کد با درخواست‌های بعدی متفاوت‌اند. هیچ تعرفه‌ای تا تأیید مدیریت برای دریافت وجه استفاده نمی‌شود. پس از تکمیل پنل امن مدیریت، تعرفه و قوانین از همان پنل تنظیم خواهند شد.

## معماری
- Worker: رابط مینی‌اپ، API و webhook مهاجرتی
- D1: کاربران، خدمات، پیش‌نویس فرم، پرونده، پرداخت، اعتبار، رسید، مدارک، تیکت، اپراتور و گزارش حسابرسی

- Secrets: توکن ربات و کلیدهای درگاه خارج از Git
