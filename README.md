# کمک‌یار مهاجر

ربات خدماتی تلگرام «کمک‌یار مهاجر» برای ارائه خدمات به مشترکان:
- 🪪 تثبیت هویت
- 📝 کد رهگیری خودنویس

## اجرا
1. Python 3.12+ نصب کنید.
2. وابستگی‌ها را نصب کنید:
   `pip install -e .`
3. متغیرهای لازم را در محیط اجرا تنظیم کنید؛ حداقل `BOT_TOKEN`.
4. اجرا:
   `python -m app.main`

## اتصال پرداخت آنلاین واریزا
برای فعال‌کردن پرداخت آنلاین، این متغیرها را در محیط امن سرویس تنظیم کنید:
- `VARIZA_API_KEY`: کلید API واریزا
- `VARIZA_WEBHOOK_SECRET`: کلید امضای وب‌هوک واریزا
- `PUBLIC_BASE_URL`: دامنه عمومی HTTPS سرویس، بدون اسلش انتهایی

پس از استقرار روی دامنه عمومی، مقدار `callback_url` را در پروفایل واریزا روی
`PUBLIC_BASE_URL/webhooks/variza` قرار دهید و ذخیره کنید. مسیر بازگشت کاربر
`PUBLIC_BASE_URL/payments/return` است. مسیر وب‌هوک فقط رویداد امضاشده را قبول می‌کند؛
پس از تطبیق شناسه لینک و مبلغ، پرداخت را به‌صورت اتمی و فقط یک‌بار ثبت می‌کند.
پرداخت کارت‌به‌کارت و بررسی رسید دستی همچنان در دسترس می‌ماند.

برای امنیت، کلید API و کلید وب‌هوک را در GitHub، کد یا گفتگو ذخیره نکنید؛
آن‌ها را فقط در متغیرهای محرمانه محیط اجرا قرار دهید.

## امنیت
- توکن ربات و شناسه مدیران هرگز داخل کد یا GitHub قرار نمی‌گیرند.
- اطلاعات هر درخواست با شناسه درخواست مستقل ذخیره می‌شود.
- قیمت و اطلاعات کارت در تنظیمات قابل تغییر طراحی شده‌اند و هاردکد نمی‌شوند.

## معماری
هسته برنامه از لایه تلگرام جدا نگه داشته شده تا در مرحله بعد بتوان رابط بله را بدون بازنویسی منطق کسب‌وکار اضافه کرد.
