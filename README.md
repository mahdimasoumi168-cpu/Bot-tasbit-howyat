# کمک‌یار مهاجر

ربات خدماتی تلگرام «کمک‌یار مهاجر» برای ارائه خدمات به مشترکان، ثبت پرونده، پیگیری درخواست‌ها، اعتبار داخلی و فروش اشتراک VPN.

## اجرا
1. Python 3.12+ نصب کنید.
2. وابستگی‌ها را نصب کنید: `pip install -e .`
3. متغیرهای لازم را در محیط اجرا تنظیم کنید.
4. اجرا: `python -m app.main`

## روش‌های پرداخت فعال
- **کارت‌به‌کارت:** ثبت رسید و تأیید دستی توسط مدیریت.
- **درگاه پرداخت رمز پویا (ریالت‌پی):** پرداخت آنلاین برای پرونده‌ها، افزایش اعتبار و خرید VPN؛ تأیید فقط پس از استعلام سمت سرور از API ریالت انجام می‌شود.
- اعتبار داخلی نیز برای پرداخت درخواست‌ها قابل استفاده است و درگاه جداگانه محسوب نمی‌شود.

درگاه واریزا و سایر درگاه‌های قدیمی در مسیرهای فعال ربات استفاده نمی‌شوند. مدل و جدول تراکنش‌های قدیمی برای حفظ سوابق تاریخی باقی می‌مانند.

## محدودیت ریالت‌پی
مبلغ هر پرداخت آنلاین باید بین ۵۰٬۰۰۰ تا ۱۰٬۰۰۰٬۰۰۰ تومان باشد. برای مبالغ خارج از این بازه، گزینه کارت‌به‌کارت در دسترس می‌ماند.

## VPN و گذربان
پس از تأیید قطعی پرداخت ریالت، ربات از API گذربان برای ساخت یا بازیابی اشتراک استفاده می‌کند. نام کاربری گذربان برای هر پرداخت ثابت است تا ارسال دوباره وب‌هوک اشتراک تکراری نسازد.

## متغیرهای محیطی
- `BOT_TOKEN`, `DATABASE_URL`, `ADMIN_IDS`
- `RIALIT_API_KEY`, `RIALIT_WEBHOOK_IPS`, `PUBLIC_BASE_URL`
- `GOZARBAN_API_TOKEN`, `GOZARBAN_PLAN_ID`, `GOZARBAN_API_ROOT`

کلیدهای API فقط در Secret Variables محیط اجرا نگهداری می‌شوند و نباید در مخزن یا پیام‌های ربات قرار بگیرند.

## امنیت و نگهداری داده
- وب‌هوک ریالت از IPهای مجاز پیکربندی‌شده پذیرفته می‌شود.
- مبلغ و وضعیت پرداخت از پاسخ استعلام سرور تعیین می‌شود، نه از پارامتر برگشت مرورگر.
- تأیید سفارش و افزایش اعتبار با به‌روزرسانی شرطی انجام می‌شود تا پرداخت تکراری به اعتبار مضاعف تبدیل نشود.
- توکن ربات، کلیدهای درگاه و توکن گذربان نباید در GitHub قرار بگیرند.
- اطلاعات سفارش‌ها، کاربران، موجودی‌ها و سوابق پرداخت نباید در فرایند استقرار حذف شوند.
